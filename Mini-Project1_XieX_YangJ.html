Part(a) - Is the player’s performance, as quantified by the amount of experience points gained changing over time?

CODGames2_mp$Date <- as.Date(CODGames2_mp$Date, format = "%m/%d/%Y")
CODGames2_mp$Month <- month(CODGames2_mp$Date, label = TRUE, abbr = FALSE, locale = "English")

ggplot(CODGames2_mp, aes(x = Month, y = TotalXP, fill = Month)) +
  geom_boxplot() +
  theme_minimal() +
  labs(title = "Boxplot of TotalXP Across Months",
       x = "Month",
       y = "TotalXP") + 
  scale_fill_manual(values = c("red", "cyan", "yellow"))

Looking at the boxplot, we don’t think there’s a large difference in the total experience of the player gained in the three months of June, July, and August because the box is in roughly the same location. However, we found that the number of experience this player gained in July showed more values that were higher. Our guess is that there is a possibility that this is caused by the fact that this player is spending more time playing Call of Duty during the summer. For proof of our conclusion, we use an anova test.

anova_model <- aov(TotalXP ~ Month, data = CODGames2_mp)
anova_summary <- summary(anova_model)

anova_df <- data.frame(
  Source = c("Month", "Residuals"),
  Df = c(anova_summary[[1]]$Df[1], anova_summary[[1]]$Df[2]),
  F_value = c(anova_summary[[1]]$`F value`[1], NA),
  P_Value = c(anova_summary[[1]]$`Pr(>F)`[1], NA))

kable(anova_df, format = "html", digits = 3) %>%
  kable_classic(full_width = F, html_font = "Times New Roman")
Source Df F_value P_Value
Month 2 0.082 0.921
Residuals 208 NA NA

There is no good reason to reject the original hypothesis, so we don’t think there is a significant difference in the amount of XP values gained with the passage of time.

Looking through the plots, this is a more obvious linear relationship, as when the number of eliminations is higher, the score tends to be higher. We can verify our hypothesis with linear regression.

model1 <- lm(Score ~ Eliminations, data = CODGames2_mp)
summary_model1 <- summary(model1)

coefficients_df <- as.data.frame(summary_model1$coefficients)
colnames(coefficients_df) <- c("Estimate", "Std. Error", "t value", "Pr(>|t|)")

coefficients_df <- cbind(Variable = rownames(coefficients_df), coefficients_df)
rownames(coefficients_df) <- NULL

kable(coefficients_df, format = "html", digits = 3) %>%
  kable_classic(full_width = F, html_font = "Times New Roman")
Variable Estimate Std. Error t value Pr(>|t|)
(Intercept) -69.826 147.507 -0.473 0.636
Eliminations 199.758 9.059 22.051 0.000

Since the p-value is significantly less than the sig.level, we have ample evidence to reject the original hypothesis. We can assume that as the number of eliminations is higher, the score tends to be higher.
