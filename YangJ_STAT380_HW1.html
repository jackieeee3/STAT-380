## `geom_smooth()` using formula = 'y ~ x'

Based on the plot, there is a weak negative linear relationship between sepal width and sepal length. As sepal length increases, sepal width seems to decrease.

Problem 4

ggplot(data = iris, mapping = aes(x = Sepal.Length, y = Sepal.Width, color = Species)) + geom_point() + geom_smooth(method = lm, se = FALSE) + labs(x = "Sepal Length (in cm)", y = "Sepal Width (in cm)")
## `geom_smooth()` using formula = 'y ~ x'

Based on the plot, there seems to be a positive linear relationship between sepal length and sepal width for all species. As sepal length increases, sepal width also increases. For the Setosa species, the increase seems to be larger than the species Versicolor and Virginica where the rate of increase is relatively similar.
